About This Project

This website is the result of a student project aimed at developing a warehouse management system. The goal of the project was to design and implement a functional application that allows efficient handling of warehouse operations such as inventory tracking, product management, and managing orders.

Meet the Team

  • Nagy Gergő Balázs
  • Mihályfi Dániel
  • Szilágyi Dominik
  • Menyhárt Benedek Károly

Each team member contributed to various parts of the system, including:

  • Frontend development
  • Backend logic
  • Database design
  • API integration

Technical Features

One of the key technical aspects of the system is endpoint protection. To ensure security and data integrity, the application uses authenticated access, so only registered and authorized users can interact with the system's core functionalities. All API endpoints are protected using proper authentication mechanisms to prevent unauthorized access and misuse of the platform.

Conclusion

This project demonstrates both our teamwork and our ability to apply theoretical knowledge in a practical, real-world context.
